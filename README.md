Browser-first product laboratory and tooling platform for transforming software capabilities into focused standalone products. This repository contains the Lovable-generated web app foundation (TanStack Start + Vite) used for codebase intake and interactive system visualization.

Quick start
```bash
git clone https://github.com/casey-arch0/irs-intelligence-research-systems.git
cd irs-intelligence-research-systems
npm install
npm run dev
# open the Vite URL shown in the console
```
